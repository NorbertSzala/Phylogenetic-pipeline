3️⃣ Jak odsiać złe runy? Gdzie i jak?

Masz trzy opcje – od najlepszej.

✅ OPCJA A (zalecana): w tym samym skrypcie Python

Rozszerzasz summarize_filtering_stats.py.

Dodajesz np.:

def filter_bad_runs(df, n_genomes):
    return df[
        (df["strict_kept"] >= 20) &
        (df["mean_n_taxa"] >= 0.8 * n_genomes) &
        (df["rf_consensus"] <= 0.3)
    ]


I w main():

df = collect_stats(...)
df = filter_bad_runs(df, n_genomes=20)


➡ reprodukowalne, naukowe, czyste

⚠ OPCJA B: ręcznie w Excelu / LibreOffice

Możesz jednorazowo, jeśli:

masz mało runów (np. <20)

robisz to tylko do sanity-checku

ALE:

nie do pracy dyplomowej

nie do automatyzacji

❌ OPCJA C: „na oko z drzew”

Nie.
Drzewa są walidacją końcową, nie filtrem.

4️⃣ Gdzie dodać df.sort_values(...)?

W TYM SAMYM skrypcie, po filtracji.

Minimalny schemat w main():

df = collect_stats(args.results, args.reference)

df = filter_bad_runs(df, n_genomes=20)

df = df.sort_values(
    by=["rf_consensus", "strict_kept", "mean_n_taxa"],
    ascending=[True, False, False]
)

df.to_csv(args.output / "ranked_runs.tsv", sep="\t", index=False)


Efekt:

pierwszy wiersz = najlepszy run

zero ręcznego wybierania
